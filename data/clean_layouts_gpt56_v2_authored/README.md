# Authored Clean Layouts GPT-5.6 v2

This directory stores room layouts authored one scene at a time. Furniture
categories, asset identities, positions, and yaw values originate in
`authored_proposals/`. Deterministic tooling may enrich those decisions with
HSSD metadata, frozen semantic fields, functional-partner edges, validation
results, diversity measurements, and top-down renders.

Only scenes with every hard check, diversity review, and independent semantic
review passing are listed as `accepted_clean` in `clean_manifest.jsonl`.
